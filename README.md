# 🐍 Estudos em Python

Este repositório reúne códigos, exercícios e práticas desenvolvidos durante as aulas de **Python** na faculdade.

O objetivo é registrar meu aprendizado, organizar os conteúdos estudados em sala de aula e acompanhar minha evolução na programação, desde os conceitos fundamentais até exercícios mais elaborados.

## 📚 Conteúdos abordados

- Fundamentos da linguagem Python;
- Variáveis e tipos de dados;
- Operadores aritméticos e lógicos;
- Estruturas condicionais;
- Estruturas de repetição;
- Listas e outras estruturas de dados;
- Funções;
- Resolução de exercícios e desafios de lógica de programação.

## 🎯 Objetivo do repositório

Utilizar este espaço como um registro da minha jornada de aprendizado em programação, mantendo meus códigos organizados e disponíveis para consultas, revisões e futuras melhorias.

Os códigos representam minha evolução acadêmica e prática no desenvolvimento de soluções utilizando Python.
